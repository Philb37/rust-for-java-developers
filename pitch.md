# Rust for Java Developers

Rust! You've surely heard of it: this "new" language is showing up everywhere, from the Linux kernel to cloud infrastructure, to the point that "Rewrite it in Rust" has become a meme. But what does it actually have to offer a Java developer?

In this talk, we'll give in to temptation: migrate a Spring Boot REST API to Rust from start to finish, partly through live coding. At each step, we'll compare Rust concepts to their Java equivalents: `Option` and `Result` versus `null` and exceptions, traits versus interfaces, ownership versus the garbage collector... and discuss the pros and cons of each language. Don't worry, no prior Rust knowledge is required. As for Java, solid fundamentals are all you need to get the most out of it!

Faster? More robust? Too hard to pick up? Come see the comparison and make up your own mind!

P.S. Feel free to join me if you're looking for a breath of fresh, AI-free air!
