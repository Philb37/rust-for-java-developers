# Rust for Java Developers

Rust ! Vous en avez forcément entendu parler : ce "nouveau" langage s'invite partout, du noyau Linux aux infrastructures cloud, au point que "Rewrite it in Rust" est devenu un mème. Mais concrètement, qu'a-t-il à offrir à un développeur Java ?

Dans ce talk, nous allons justement céder à la tentation : migrer une API REST Spring Boot vers Rust de bout en bout, en partie en live coding. À chaque étape, nous comparerons les concepts de Rust à leurs équivalents Java : `Option` et `Result` face à `null` et aux exceptions, les traits face aux interfaces, l'ownership face au garbage collector... et évoquerons les avantages et inconvénients de chacun des languages. Pas d'inquiétude, aucune connaissance en Rust n'est requise. Quant à Java, de bonnes bases suffisent pour en profiter pleinement !

Plus performant ? Plus robuste ? Trop difficile à prendre en main ? Venez découvrir le comparatif pour vous faire votre propre avis !

PS : N'hésitez pas à me rejoindre si vous voulez prendre un bol d'air frais sans IA !
